# highloadDZ2026
Домашнее задание по курсу "Проектирование высоконагруженных систем". 
В данной работе будет рассмотрена архитектура сервиса искусственного интеллекта Claude от компании Anthropic. 
Модели от Anthropic являются одними из лидеров рынка искусственного интеллекта, наравне с ChatGPT от OpenAI и Gemini от Google.
Месячные активные пользователя сервиса измеряются десятками миллионов, высокая нагрузка и по RPS, и по GPU вычислениям делают архитектуру нетривиальной и интересной к рассмотрению.
